# Prompt pack for the paper pieces

Every prompt below is complete: the style prefix is already in it, so copy one block, paste it into the image model
(GPT Image or similar), save the result under `public/art/paper/` with the exact file name, and reload. The site loads
pieces by name. Then run `python3 tools/defringe.py <file>` and `python3 tools/restyle.py <file> --rim 6` (`--body` for
Chimin if any snow got drawn around her).

## Rules that make them fit
- **Transparent background.** If the model cannot, ask for a plain pure-white background and I cut it out.
- **Front view, camera a little above** (about 15° down) for objects, so they sit together. The snow-angel figure is seen from directly above.
- **Light from the upper left**, soft. **No cast shadow on the ground** and no drop shadow: the scene adds those.
- **Paper, not paper-cut**: patches of colour with paper texture and soft feathered edges, gently shaded, no torn edges or rim, no gloss, no 3D render look, no outline heavier than a pencil.
- **Nothing else in the picture**: one thing, centred, generous margin, no text, no ground, no props.
- 1024 px or larger, PNG, the aspect given.

The site already frosts, grains, glistens and shades every piece in the shader, so no sparkle or heavy modelling needs drawing in. The hand is paper-textured but not cut out: soft feathered edges, a little rounding in the shading, no torn rim.
